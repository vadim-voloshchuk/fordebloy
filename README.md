# Проект: Графовая визуализация и анализ ♾️✨

Добро пожаловать в наш небольшой, но увлекательный мир графов! В этом проекте мы объединили веб-приложение на базе **React** (фронтенд) и **Flask** (бэкенд), чтобы вы могли **интерактивно** работать с графами: создавать их, модифицировать, анализировать и визуализировать результаты прямо в браузере. Ниже — общая концепция и принципы, которые лежат в основе этого решения.

## Общая идея ☝️

Мы хотим дать пользователям (**вам!**) инструмент для:

1. **Создания** и **редактирования** графа:  
   - Добавлять и удалять вершины, рёбра.  
   - Настраивать типы (ориентированные/неориентированные) и веса связей.  

2. **Вычисления** важных характеристик:  
   - Кратчайшие пути (например, через алгоритм Дейкстры).  
   - Матрицу кратчайших расстояний (Флойд—Уоршелл).  
   - Метрики центральности, радиус и диаметр графа.  

3. **Кластеризации** данных:  
   - Spectral Clustering, K-Means, DBSCAN и пр.  

4. **Визуализации** результатов:  
   - «Раскрашивание» кратчайших путей, подсветка кластеров и т.д.

Всё это в **одном приложении**, где фронтенд на **React** отображает интерактивную карту (библиотека для рисования графа) и общается с **Flask**-сервером, который умеет всё считать и обрабатывать.

## Что под капотом 🔧

### React (Фронтенд)

- **Компоненты** для узлов и рёбер, модальные диалоги для ввода параметров (например, окно «Shortest Path» или «Clustering»).  
- **Граф** рисуется и взаимодействует с пользователем: можно **кликнуть** по вершине, **передвигать** узлы, **выделять** их, **удалять** и т.д.  
- **Запросы** на бэкенд, чтобы, например, найти кратчайший путь или посчитать матрицу расстояний.  

### Flask (Бэкенд)

- **Принимает** структуру графа (массив вершин и рёбер) в формате JSON.  
- **Проводит** нужные вычисления (Дейкстра, Флойд—Уоршелл, кластеризацию и т.д.).  
- **Возвращает** результаты обратно в JSON, которые фронтенд затем «рисует».

## Архитектура взаимодействия 🌐

1. **Пользователь** в браузере открывает страницу → видит **визуализацию**.
2. При необходимости, пользователь **вызывает** модальное окно (например, «Найти кратчайший путь»).  
3. **React** формирует JSON с данными графа и отправляет POST-запрос на определённый эндпоинт во Flask.  
4. **Flask** рассчитывает нужную характеристику (алгоритм, матрицу, и т.д.) и **возвращает** результат.  
5. **React** получает ответ и **перерисовывает** граф (например, рисует кратчайший путь красной линией).  

Всё происходит **динамически** и **без перезагрузки** страницы.

## Зачем это нужно? 🤔

- **Учебные цели**: Проект иллюстрирует, как связать фронтенд (JS/React) и бэкенд (Python/Flask) для нетривиальной задачи — работы с графами.  
- **Практические цели**: Можно применять такой подход для анализа связей в социальных сетях, визуализации дорожных сетей, графов знаний и многого другого, где нужно «смотреть» на структуру и исследовать её свойства.  

## Подробности по алгоритмам и функционалу 🧮

1. **Алгоритмы кратчайшего пути**:  
   - Алгоритм Дейкстры (исключает отрицательные веса).  
   - Алгоритм Флойда—Уоршелла (получаем расстояния между **всеми** парами вершин).  

2. **Параметры графа**:  
   - **Радиус** — минимальный эксцентриситет среди всех вершин.  
   - **Диаметр** — максимальный эксцентриситет.  
   - **Центр** — множество вершин, у которых эксцентриситет равен радиусу.  

3. **Кластеризация**:  
   - **Spectral** — метод на основе спектра матрицы смежности/лапласиана.  
   - **K-Means** — классический алгоритм разбивки на \(k\) кластеров.  
   - **DBSCAN** — метод плотностной кластеризации (не нужно заранее указывать \(k\)).  

4. **Визуализация**:  
   - Отрисовка вершин (можно «цеплять» мышкой).  
   - Отрисовка рёбер (ориентированные/неориентированные).  
   - Цветовые выделения для путей, кластеров, типов и т.д.
