# NeuroWeave RoadMap

> Последнее обновление: апрель 2025

Проект **NeuroWeave** — это веб-приложение на базе **FastAPI + React + vis.js** для анализа, визуализации и кластеризации графовых структур. Этот RoadMap документирует ключевые этапы развития и приоритеты на ближайшие месяцы.

---

## Этап 1: Базовая функциональность (апрель — май 2025)

| Подзадача | Статус | Комментарий |
|-----------|--------|-------------|
| Загрузка и визуализация графов через vis.js | ✅ Готово | Поддержка типов узлов и рёбер, подписи, веса |
| Расчёт матрицы кратчайших расстояний (Floyd-Warshall) | ✅ Готово | Через FastAPI с поддержкой направленности |
| Расчёт кратчайшего пути (Dijkstra) | ✅ Готово | Поддержка фильтрации по типам |
| Расчёт характеристик графа (центр, радиус, диаметр, центральности) | ✅ Готово | Backend API `/graph/characteristics` |
| CRUD узлов и рёбер | ✅ Готово | Через UI и интерактивную сетку |
| Сохранение/загрузка графа | ✅ Готово | В локальный JSON или через API |
| Отображение информации о графе | ✅ Готово | Сводка в `GraphInfoPanel` |
| UI-адаптация под ПК и мобильные устройства | 🟡 Частично | Мобильная версия ограничена |

## Этап 2: Расширение анализа (июнь 2025)

| Подзадача | Статус | Комментарий |
|-----------|--------|-------------|
| Кластеризация: K-Means, Spectral | 🟡 В процессе | Начало реализации через SciKit-Learn |
| Кластеризация: DBSCAN | 🔜 Запланировано | Важно для плотностной сегментации |
| PageRank, Closeness, Eigenvector Centrality | 🔜 Запланировано | Улучшение семантического анализа |
| Расширение фильтрации по типам | 🔜 Запланировано | UI-меню выбора типов узлов/рёбер |

| Подзадача | Статус | Комментарий |

## 💡 Идеи на будущее (post-release)

- Распознавание графов из изображений / OCR
- Генерация графов из текстового описания (LLM)
- Интеграция с Neo4j / NetworkX через API
- Расширенная кастомизация визуального стиля узлов и рёбер
- Возможность "графовой симуляции" (например, заражения, распространения влияния и пр.)
